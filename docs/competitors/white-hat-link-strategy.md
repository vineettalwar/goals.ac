# White-Hat Link Strategy (Alternative to Backlink Exchange)

**Workstream D** · July 2026

AutoSEO's core retention hook is a **customer backlink exchange network** (5–10 links/mo, "100 DA worth"). goals.ac explicitly rejects PBN-adjacent exchanges ([compare page FAQ](artifacts/marketing-persona-app/src/components/marketing/compare-page-client.tsx)).

---

## Marketable alternatives (ranked)

### MVP Option A — Internal Link Hub (ship first)

**Status:** beta in product (`Internal link hub` in platform features)

| Element | Delivery |
|---------|----------|
| Auto-suggest contextual internal links during generation | Live in content pipeline |
| Cluster map from site graph + sitemap | Plugin + brand scan |
| Publish-time link injection | CMS adapters |

**Marketing angle:** *"Build authority with content clusters — the links Google trusts, not link farms."*

**Effort:** Medium — surface existing beta in autopilot dashboard + lander copy.

### MVP Option B — Citation-Worthy Content Formats

| Format | Link magnet potential |
|--------|----------------------|
| Original data / benchmark posts | High |
| Free tools (calculators, checklists) | High |
| Comprehensive guides (2,500+ words) | Medium |

**Marketing angle:** *"Earn links with content worth citing — we optimize structure, schema, and depth for linkability."*

**Effort:** Medium — template formats in content studio + quality score for "linkability."

### Phase 2 — Digital PR Assist (not MVP)

- HARO/Connectively alert surfacing
- Outreach email drafts for data studies
- **Do not** automate spam outreach

### Rejected

- Backlink exchange / link trading networks
- Fiverr-style bulk backlinks
- Reddit auto-posting for links

## Positioning vs AutoSEO

| AutoSEO | goals.ac |
|---------|----------|
| "5–10 backlinks/month from our network" | "Internal link clusters + citation-worthy depth" |
| DA metrics as hero number | GEO score + GSC clicks as hero metrics |
